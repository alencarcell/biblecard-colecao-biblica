# BibleCard — Coleção de Estudo Bíblico

Projeto editorial independente para criação de cartões colecionáveis de personagens e povos mencionados na Bíblia, com conteúdo fundamentado prioritariamente na Tradução do Novo Mundo e nas publicações oficiais disponíveis em **jw.org**.

## Comece por aqui

1. Leia [`CONTINUIDADE_BIBLECARD.md`](CONTINUIDADE_BIBLECARD.md). Este é o arquivo mestre de instruções.
2. Consulte [`catalogo/STATUS_DA_COLECAO.md`](catalogo/STATUS_DA_COLECAO.md) antes de criar qualquer carta.
3. Ao iniciar um novo chat, envie o link do repositório e peça: **“Leia o arquivo CONTINUIDADE_BIBLECARD.md e continue a BibleCard do ponto registrado.”**

## Identidade do projeto

- Marca oficial: **BibleCard**
- Coleção: **Personagens da Bíblia — Coleção de Estudo Bíblico**
- Cartões frente e verso.
- Dimensão física de cada carta: **4 × 5,5 cm**.
- Embalagem planejada: **25 cartas por envelope**.
- Identidade visual predominante: azul-marinho e dourado.
